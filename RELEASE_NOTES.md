## QuickSetTiles v1.0.2

### 🌟 What's Changed
  - **Split Apps**: Pair any two installed applications and launch them together in dual split-screen / multi-window mode directly from Quick Settings.
  - **Contacts Tile**: Added dedicated Contacts tile type with Phone Dial (direct call/SIM chooser) and Message (SMS conversation) options.
  - **Permissions Onboarding**: Intuitive first-launch permissions onboarding page for Shizuku, Phone, Contacts, and Notification access.
  - **Collections Tray Drag & Drop**: Visual drag-and-drop reordering for tiles inside the Collections creation preview tray.
  - **Clean QS Edit Panel**: Excludes unadded/inactive tiles from Android's system Quick Settings edit sheet.
  - **Lock Screen Privacy**: Completely hides tiles configured with "Hide on lock screen" while the device is locked.
